# Chain logos

Logos of the store chains shown as tiles in the store directory (`components/stores/chain-logo.tsx`).
File name = lower-case chain name (`lidl.svg`); a chain without a file gets a coloured tile instead.

| `billa.svg` | https://commons.wikimedia.org/wiki/File:Billa-Logo.svg | Public domain; registered trademark |
| `penny.svg` | https://commons.wikimedia.org/wiki/File:Penny-Logo.svg | Public domain; registered trademark |

The logos are trademarks of their owners and appear only to identify the chain's own branches.
Albert and JIP have no logo with a clear licence here; add `albert.svg` / `jip.svg` yourself
(the owner supplies them) and the tiles pick them up — see `LOGO_FILES` in the component.
